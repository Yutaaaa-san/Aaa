WordHunter No-Login — iPhone Safari用に公開する手順
================================================

重要：
- このZIP自体をiPhoneで開いても、サーバー処理は動きません。
- iPhoneから使うには、Webホスティングサービスに一度公開してHTTPSのURLを作る必要があります。
- このZIPは公開用のファイル一式です。こちら側からあなたのアカウントに公開することはできません。
- 公開プロフィールが検索できないことは、Xboxで取得可能という意味ではありません。
- 外部サイトの仕様変更・アクセス制限により照合が動かないことがあります。
- 大規模なスキャンには非常に長い時間がかかります。

簡単な公開手順（Renderを使う例）
1. ZIPを展開します。
2. GitHubにログインし、新しいリポジトリを作ります。
3. 展開した中身をリポジトリへアップロードします（ZIPファイルそのものではなく、中のファイル）。
4. Render.com にアクセスし、GitHubアカウントを接続します。
5. New + → Web Service からリポジトリを選びます。
6. render.yaml の設定が読み込まれたら作成します。読み込まれない場合は：
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app --workers 1 --threads 4 --timeout 120
7. デプロイが完了すると https://....onrender.com のURLが出ます。
8. iPhoneのSafariでそのURLを開き、「自動スキャン開始」を押します。

注意：
- ホスティングサービスの仕様・無料枠は変更されることがあります。スリープするプランではスキャンが中断する可能性があります。
- 公開URLを知っている人が操作できる可能性があります。個人用のまま使い、URLを他人に共有しないでください。
- サービスの制限により、外部サイト照合が失敗する場合があります。
- このツールはXbox公式の空き状況APIを使っていません。結果は「使用できる可能性あり」という推定候補です。
