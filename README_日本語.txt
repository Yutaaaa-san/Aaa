WordHunter No-Login（公開プロフィール照合版）
=============================================

できること
- Microsoft/Xboxへのログインなしで動作
- 英単語辞書を自動取得し、3〜12文字の英字のみの候補を順番に照合
- XboxGamertag.comの公開プロフィール検索とDuckDuckGoの検索インデックスを確認
- どちらにもプロフィールが見つからなかった候補を「使用できる可能性あり」と表示
- 結果を自動保存し、再開時に確認済み候補をスキップ
- 外部サイトの拒否・制限・通信エラーは空き扱いにしない

重要な制限
- これはXbox公式の空き状況APIではありません。プロフィールが検索できないことは、Xboxで取得可能という意味ではありません。
- 使える可能性がある候補を探すための推定ツールです。最後はXbox公式のゲーマータグ変更画面で確認してください。
- 1候補につき最低4秒の間隔を設けています。数十万候補の全件照合には非常に長い時間がかかります。
- 外部サイトの仕様変更やアクセス制限で照合できなくなる可能性があります。

起動方法（Windows PCが必要）
1. ZIPをWindows PCで展開
2. Python 3.10以上をインストール（PATH追加を有効にする）
3. 展開したフォルダでコマンドプロンプトを開き、次を実行：
   py -m pip install -r requirements.txt
   py app.py
4. PCで cmd を開き「ipconfig」を実行し、IPv4アドレスを確認
5. iPhoneとPCを同じWi-Fiに接続
6. iPhoneのSafariで http://PCのIPv4アドレス:8765 を開く
   例： http://192.168.1.23:8765
7. 「自動スキャン開始」を押す

このツールはPC上のサーバーで動きます。HTMLファイル単体をiPhoneで開いてもスキャンできません。サーバーをインターネットへ公開せず、同じWi-Fi内だけで使ってください。
